# H.E.R.A.L.D.

**H**elping **E**veryone **R**ecognize **A**ll **L**ands' **D**esigns — kartičky na vlajky všetkých 197 štátov sveta (hlavné mesto, rozloha, obyvatelia, zaujímavosť), po kontinentoch.

- Režimy **Učenie**, **Skúšanie** (náhodne) a **Prehľad** s vyhľadávaním
- Inštalovateľná PWA, funguje aj **offline**

Rozloha a obyvatelia: CIA World Factbook (odhady 2024–2025). Vlajky: Wikimedia Commons (cez hampusborgos/country-flags).
